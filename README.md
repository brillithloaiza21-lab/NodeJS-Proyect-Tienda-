## Proyecto: API Mi Tienda de Barrio

API para gestionar los productos de la tienda de don Pedro.

- **Aprendiz:** Cristian david correa agudelo

## Estructura

- `data/` – los datos (productos)
- `utils/` – funciones de ayuda (formato de precios y nombres)
- `servicios/` – acciones del negocio (buscar, agotados, valor del inventario)
- `app.js` – programa principal
